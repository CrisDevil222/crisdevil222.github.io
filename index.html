    View hackathon project & case study

    ClubFund Guard

    Challenge 2 "UNLOCKED" by Tide (Prototype with TideCloak, where no single admin, organization, or AI can bypass the rules).

    AI assistant for student club finances: AI reads ledgers and drafts expense proposals but NEVER executes transactions autonomously; funds can only be disbursed after approval from 2 out of 3 managers. Spending authority is a designated role; granting this role creates a TideCloak change request requiring a 2/3 administrator quorum approved from their respective browsers in Tide enclaves. The API verifies DPoP-bound tokens and returns 403 if the role is missing, leaving an immutable audit trail.

    Limitations: AI assistant is a rule-based mock implementation, and financial data is simulated. Real LLMs and live money are not integrated.
    • TideCloak
    • Next.js
    • Node.js
    • JavaScript
    • Docker
    Event page Repo Demo video

    Problem

    Student clubs traditionally rely on a single treasurer, and autonomous AI acting alone only magnifies operational risk.

    Approach

    Separated operational responsibilities: AI drafts proposals, humans make governance decisions, and cryptography enforces authorization.

    Key decisions

    Treated disbursement authority as an explicit role, utilized TideCloak's 2/3 decentralized quorum instead of trusted server flags, and validated DPoP cryptographic tokens at the API gateway.
